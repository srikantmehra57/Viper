# Selected direction: The Darkroom

User selection: Darkroom. Implement locally, without external generation or deployment.

## Emotional thesis
Relief through understanding. Viper lets you inspect, review, and decide; the website should feel like bringing a photograph into focus. Real app captures carry the story. The site is a carefully lit viewing room for the product.

## Visual commitment
- Warm charcoal #10100f; chalk #efede5; muted silver #aaa79d; champagne #d8bc85.
- Bodoni Moda for expressive editorial headlines; IBM Plex Sans for readable content; IBM Plex Mono for captions and controls. All fonts bundled locally.
- Every major composition and heading uses a centered axis. Intentionally overlapping screen photographs create depth within it.
- No generic geometric 3D sculpture, gradient headline, icon-card features, two-button hero, or repeated scroll fades.

## Signature moments
1. Shallow Three.js product photograph stack. Drag or use the feature controls to select a real screen; spring movement settles immediately afterward. Static fallback and reduced-motion behavior preserve information.
2. Oversized serif type meets a centered application window, followed by full-screen product photographs and close crops as editorial spreads.
3. A restrained champagne exposure line traces the selected screen and settles. Captions describe real app behavior rather than invented visual metadata.

## Build scope
One existing route, complete responsive redesign, centered header navigation, screen selector, fullscreen image inspection, local-build dialog, copy commands, footer. No publication, no app behavior changes, no invented download.

## Image policy
Actual Viper screenshots captured locally through the native app. Use controlled demo files for storage if capture can be completed. Never alter screenshots to invent product capabilities. Captions distinguish demonstration data and idle states.
